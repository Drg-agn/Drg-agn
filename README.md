<details>
<summary><b>⬡ &nbsp;NextVault — AI-Powered Full-Stack Banking System</b></summary>

<br/>

A production-grade digital banking platform with a complete backend built on secure authentication, role-based access control, and real-time transaction infrastructure. Integrated with an AI-powered customer support chatbot and Razorpay's payment gateway for seamless financial operations. Built to simulate enterprise-grade banking workflows in a full-stack JavaScript environment.

| Attribute | Detail |
|:---|:---|
| **Stack** | Node.js · Express.js · MongoDB · React · Razorpay API · OpenAI API · Docker · Render |
| **Architecture** | Monorepo with separate `/backend` and `/frontend` modules |
| **Security** | JWT authentication · Role-based access control · Secure session handling |
| **AI Feature** | Integrated AI chatbot for real-time customer support and query resolution |
| **Payments** | Razorpay payment gateway integration for banking transactions |
| **Deployment** | Containerised with Docker · Deployed on Render |
| **Repository** | [![View](https://img.shields.io/badge/View%20Repo-7C3AED?style=flat-square&logo=github&logoColor=white)](https://github.com/Drg-agn/NextVault) |

The platform implements a layered security architecture: users authenticate via JWT tokens with role-based access tiers, separating admin and customer scopes. The AI chatbot layer is powered by OpenAI's API, enabling context-aware responses to banking queries without manual intervention. Transaction events trigger real-time notifications, and the Razorpay integration handles payment lifecycle management end-to-end. The entire stack is containerised for reproducible deployments.

</details>

<details>
<summary><b>⬡ &nbsp;HuntFlow — Automated Cold Outreach & Job Application Platform</b></summary>

<br/>

A full-stack automation platform that eliminates the manual overhead of job hunting. HuntFlow scrapes live remote job listings, generates personalised cold emails using AI, and delivers them through an automated workflow — all driven by a clean React frontend with configurable filters. Built for developers actively seeking remote roles who want to apply at scale without sacrificing personalisation.

| Attribute | Detail |
|:---|:---|
| **Stack** | React · Vite · Node.js · Express.js · N8n · Remotive API · SMTP/Nodemailer · Render · Vercel |
| **Automation** | N8n workflow pipeline for end-to-end job scraping, email generation, and delivery |
| **Data Source** | Remotive API for live remote job listings across roles and stacks |
| **AI Feature** | Personalised cold email generation per job listing and applicant profile |
| **Frontend** | React dashboard with role, tech stack, and location filters · Email preview before dispatch |
| **Deployment** | Backend on Render · Frontend on Vercel |
| **Repository** | [![View](https://img.shields.io/badge/View%20Repo-7C3AED?style=flat-square&logo=github&logoColor=white)](https://github.com/Drg-agn/HuntFlow) |

The system is orchestrated via N8n: a webhook trigger fires when a user submits their configuration, kicking off a multi-stage workflow that fetches matching job listings from Remotive, passes each listing through an AI prompt template to generate a tailored cold email, and routes the output through Nodemailer for SMTP delivery. The React frontend decouples the user configuration experience from the backend pipeline — users can preview and approve email drafts before committing to dispatch, giving human oversight over the automation loop.

</details>

<details>
<summary><b>⬡ &nbsp;Stock Swing Analyzer — Multi-Factor NSE Stock Scoring Engine</b></summary>

<br/>

A full-stack MERN application that delivers data-driven swing trade signals for NSE-listed stocks using a proprietary four-section scoring model. Combines live market data from Yahoo Finance with fundamental data scraped from financial sites to produce ranked BUY / WATCH / AVOID recommendations — all computed in real time across up to five concurrent stocks.

| Attribute | Detail |
|:---|:---|
| **Stack** | React · Node.js · Express.js · MongoDB · Yahoo Finance v8/v10 API · Cheerio · Axios · Railway · Vercel |
| **Scoring Model** | Trend (35%) · Technical (30%) · Momentum (20%) · Quality (15%) |
| **Live Data** | Auto-fetched: price, SMA50/200, MACD, ROE, ROCE, EPS CAGR via Yahoo Finance API |
| **Scraping** | HTML scraping via Cheerio/Axios for supplementary fundamental data |
| **Concurrency** | Supports simultaneous analysis of 5 NSE-listed stocks with ranked signals |
| **Deployment** | Backend on Railway · Frontend on Vercel |
| **Repository** | [![View](https://img.shields.io/badge/View%20Repo-7C3AED?style=flat-square&logo=github&logoColor=white)](https://github.com/Drg-agn/stock-analyzer) |

The scoring engine is implemented as a configurable multi-factor model: technical signals (SMA crossovers, MACD) contribute 30% of the final score while trend indicators account for 35%, enabling the engine to weight momentum and quality factors independently. Live data is fetched from Yahoo Finance's v8 and v10 endpoints, while Cheerio-based HTML scraping supplements the dataset with fundamental metrics not exposed via API. The system processes concurrent requests for up to five tickers, ranks them by composite score, and emits colour-coded signals to assist swing trading decisions.

</details>
